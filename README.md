## 🚀 Getting Started

Prerequisites: Node.js 20.9+, npm.

```bash
git clone https://github.com/Pa004/portfolio.git
cd portfolio
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

Verify with `npm run test:run` and `npm run lint`.
